# Phase 1.6.5 prospective recording and view selection

Frozen before viewing candidate footage for this phase. Use the existing recording series and the native 1920×1080 canvas with the fixed study window `736 ≤ x < 1184`, `364 ≤ y < 716`. Review screen pixels and the history around those pixels. Use non-glyph wall geometry for registration and deduplication. Marker inspection is limited to establishing the visibility change. Marker totals, bounding-box coverage, input fitness and matcher results play no part in selection.

1. Exclude every layout in the pilot or subsequent annotation, development, calibration and holdout records. The remaining footage-only review candidates are `mapa-01`, `mapa-02`, `mapa-03`, `mapa-04`, `mapa-05`, `mapa-08` and `mapa-10`, in that order. Earlier target-intake screenshots from these recordings are footage review. The used-layout exclusion list is `mapa-07`, `mapa-06` and `mapa-09`. Check the recording and distinguish its observed wall topology, preferably around the Level 1 arrival as well as the selected region, from the three used layouts. Record the limits of visual deduplication.
2. Start with a visual pass of the successive automap states across the Level 2 footage, in chronological order, using thumbnail contact sheets, then inspect relevant wall junctions and visibility events at native resolution. At each plausible visibility transition, inspect the neighboring frames in recording order. Select the earliest moved-view event with a reproducible visibility difference in **both** directions, confirmed by actual source pixels. For that event use stable readable source frames on the two sides. Use the earliest readable primary frame and then the earliest readable moved frame among the near-event frames that satisfy the screens below. Chronological order refers to decoded PTS. A brief scene effect can establish a real change when a particular glyph is clear before and after the effect and its intervening occlusion is visible beside registered walls. Neither small rendering differences nor induced black padding count as disappearance. A glyph changed solely by the imposed study-window edge cannot establish a direction of genuine change.
3. Require a clear player mark in both views, overlapping registered windows and recognizable shared non-glyph structure, with changed registered player position greater than the summed player marking and wall-transfer allowances. At least one independently inspectable glyph present in each source must have a documented reason it is unreadable or unrendered at the corresponding location in the other source. Use stable wall cues and neighboring frames to distinguish glyphs from transient scene pixels and to separate reveal, occlusion and native clipping from the imposed window.
4. For the first repeat event that passes, use the earliest readable distinct-region frame in the chronological contact-sheet sample that is within the same Level 2 run, has a visible player, registers successfully and has a registered window separated from both repeat windows by more than 12 px on at least one axis. Use a stable same-recording late frame where possible. Separate late frames may serve as references only with a verified common translation between them. Use the existing longest-baseline fit and non-glyph held-out wall checks with the fixed transfer allowance. Choose the first layout with a qualifying trio. Log screened alternatives or the specific blocker for each examined layout necessary to justify the selection.
5. If the remaining recordings do not supply a qualifying trio, document which screen cannot be verified and stop within the one-layout cap. Package only the three selected source frames, two blinded reviews each.
