# Feasibility verdict

**CONDITIONAL GO.** Authorize only a small offline experiment after the owner confirms access to an independently labelable D2R sample. The blocker is evidence about visible geometry on unseen D2R layouts. There is no executable Phase 0 benchmark and no real accuracy, coverage or resource result. Source inspection makes the question worth a small test and leaves both outcomes open. If independent recordings or dependable labels cannot be obtained, the D2R decision remains blocked. [F-01](FINDINGS.md#f-01) · [Audit](PHASE_0_AUDIT.md)

## Executive summary

| Question | Answer |
| --- | --- |
| 1. What did Phase 0 prove? | It established the scope, a plausible classic test area, a source-supported path to optional known-seed classic generation and a reproducible benchmark design on paper. The workspace can run standard-library Python. |
| 2. What did it fail to prove? | Early D2R NEXT or WP accuracy on unseen maps, classic-to-D2R parity, reliable translation from actual automap imagery, and operation within desktop performance budgets. No game-level experiment was executed. |
| 3. What are the three most dangerous assumptions? | That early geometry materially improves on entrance orientation for both targets, that the useful geometry and coordinates are recoverable from real D2R pixels, and that a finite reference corpus represents actual D2R layouts and target frequencies. [A-04](ASSUMPTIONS_REGISTER.md) · [F-04](FINDINGS.md#f-04) · [F-07](FINDINGS.md#f-07) |
| 4. What is the most important technical blocker? | No independent D2R sample joins blind early observations and player positions to verified, still-hidden Level 3 and waypoint outcomes on distinct layouts. [F-01](FINDINGS.md#f-01) |
| 5. Is the current architecture unnecessarily complicated? | A one-file-input CLI, simple prior and abstention are proportionate. A general fixture generator, simulator, full-map matcher and classic adapter are premature before the real-image signal pilot. [F-02](FINDINGS.md#f-02) |
| 6. What should be removed from the first slice or postponed? | Seed reconstruction, full-map indexing, generic graph matching, raster templates, extraction automation, classic asset integration, overlay/UI, and coordinate estimates. Keep a few synthetic contract cases and an optional classic diagnostic after the pilot. |
| 7. What algorithm currently has the strongest evidence? | The orientation-conditioned empirical prior is the most defensible lightweight baseline. Classic source supports testing orientation cues. No algorithm has empirical D2R predictive evidence. A few additional local geometry cues are the simplest useful comparison. |
| 8. What is the simplest viable experiment? | In one recorded D2R context, have annotators transcribe visible geometry before either target's later reveal. Compare the entrance prior to that prior plus a few visible connectors on held-out layouts, independently for each target. [Experiment](PHASE_1_RECOMMENDATIONS.md#smallest-vertical-slice) |
| 9. What should be validated before writing more code? | Source authorization, independent layouts, observable entrance/room geometry, player and landmark frame alignment, per-target eligibility and a feasible statistical evidence budget. A classic exporter, if used, needs its own independent anchor and provenance tests. [F-03](FINDINGS.md#f-03) · [F-06](FINDINGS.md#f-06) · [F-09](FINDINGS.md#f-09) |
| 10. Should Phase 1 proceed? | Only after owner approval and a demonstrated input path, with the experiment narrowed to the D2R signal pilot. Advance to a larger held-out test only when the pilot makes that investment defensible. Product work depends on the recorded product gates. |

## Devil's advocate

The project can fail even with a fast and correct matcher. Most early windows may consist of reusable entrance and corridor pieces. Compatible completions may put NEXT or WP on opposite sides, and the distinguishing branch may only appear when the target is almost visible. A classic collision-based corpus would give an apparently complete graph to an evaluator while offering fewer reliable features in D2R imagery. A synthetic pass, a unique reference match and a confident-looking vote could all persist through that failure. [Identifiability](PHASE_0_AUDIT.md#what-early-imagery-can-identify) · [F-02](FINDINGS.md#f-02) · [F-05](FINDINGS.md#f-05)

Phase 0 could have exposed the inference failure with a tiny counterexample, located the bridge-centre limitation from the ABI, and treated the absence of independent recordings as a gate. Real ambiguity and presentation drift require data. The fastest tests are blind annotation agreement, target disagreement among common prefixes, and incremental predictive lift on disjoint layouts. A full search becomes unattractive if the needed corpus exceeds resource budgets, requires unverified assets or represents too little of the true distribution. No corpus size resolves opposite targets with identical allowed evidence. [F-01](FINDINGS.md#f-01) · [F-03](FINDINGS.md#f-03) · [Search sizing](PHASE_0_AUDIT.md#search-space-and-cost-sensitivity)

A small area-specific orientation or map-reading rule with an unknown state may provide most of the achievable value. If a rule clears the absolute utility target and added geometry contributes little, a rule-only tool is a plausible pivot with owner approval. If neither method offers reliable early bearings on a sufficiently informative evaluation, stop the hidden-target predictor for this scenario. A success for one landmark is grounds for discussing a narrower objective. [Measurement and decision](PHASE_1_RECOMMENDATIONS.md#measurement-and-decision)

The audit leaves the Phase 1 approval gate with the project owner. No Phase 1 implementation was started.
