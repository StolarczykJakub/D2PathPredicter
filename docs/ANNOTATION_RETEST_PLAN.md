# Phase 1.6.1 controlled annotation retest plan

The owner approved preparation of this retest on 2026-11-25. Freeze these acceptance criteria before sending any packets. The private release manifest binds this plan and [Protocol V2](ANNOTATION_PROTOCOL_V2.md) to the exact packets. These are workflow thresholds chosen for this small retest using the observed V1 player-marking scale and Stage 3 doorway span. They have no effect on version 1 benchmark scoring.

## Frames and independent handoff

- Use Stage 0 of `b16-k9w4` for arrival-room centre and entrance-facing evidence. Use Stage 3 for the wider mix of localized markers, incomplete room boundaries, shared openings, enclosures and terminal-room claims. Stage 3 covers more of these cases than Stage 2. Both are development observations from one layout.
- Issue exactly one ZIP to each of four fresh reviewers in isolated sessions. Each frame has two reviewers, with opposite semantic/raw pass orders. Reviewers cannot see other stages or returns, prior findings, target evidence, prediction results, the repository or this plan. If using isolated AI sessions, provide no prior conversation or shared files. An exposure or a prior view of the pilot makes that review ineligible.
- Send the ZIP file alone. Keep the private alias and digest manifest with Role C. Record the reviewer ID, release and receipt times, order actually followed, reported exposure or deviations, and SHA-256 of both returned JSONs. Keep original bytes under the opaque packet ID in the private V2 return store. Structural validation checks the promised frame digest, packet identity, coordinate bounds, statuses, radii, durations and references. Analyze only complete independent frame pairs whose instructions were followed. Record missing or incomplete measurements per field and preserve partial valid observations in the report.
- Each reviewer has up to eight active minutes per pass. Saving separately and reversing the order helps reveal order effects. Shared visual memory within a reviewer and the small sample still limit interpretation.

## Frozen comparison method

Match independently marked records within the same native frame. Ignore observation-local IDs. Use one-to-one matches, maximizing the number of candidates within the limits below and then minimizing summed positional distance. If multiple associations tie at the precision of the marks, record the association as ambiguous and report the affected result separately. For segment endpoints use the better direct or reversed endpoint pairing. Preserve unmatched marks on both sides. Assess visible support in the same source frame if a disagreement needs explanation and keep those notes separate. Reviewer agreement measures repeatability.

| Measure | Method and threshold |
| --- | --- |
| Player localization | Compare Euclidean pixel distance for the two reviewers in each pass. Each pass on each frame needs two observed marks, a distance at most 8 px and distance at most the sum of their marking radii. Report player-relative geometry in addition to native marks using each reviewer's own player point. For an offset, conservatively add feature and player radii, then sum between reviewers for disagreement. |
| Entrance localization | On Stage 0, require two OBSERVED arrival-room centres, distance at most 12 px and at most the summed radii, with each radius at most 12 px. Compare scene stairs, entrance glyph and player arrival mark separately in their own spaces. Apply the same 12 px and summed-radius checks when both reviewers mark one. Stage 3 gets a separate availability and agreement report. A shared unresolved status is recorded without positional agreement. |
| Entrance orientation | Derive each measurable centreline's angle using the existing eight sectors. Calculate angular half-width from the possible 2 × endpoint-radius displacement of its direction vector. If it can cross a boundary, the label is unresolved under V2. Report exact directed agreement, axis agreement modulo 180°, and unresolved states. A shared usable angle requires the same direction or same supported axis, axis difference at most 15°, and overlapping angular uncertainty intervals at the agreed level. Report directed disagreements even if reviewers agree on the axis. V1 permits pooled priors when orientation is unresolved. |
| Region centres and class | Match locatable semantic candidates within 20 px by centre, independently of class. For each match report distance and whether the sum of centre radii covers it. Report ROOM, ENCLOSED_FEATURE and UNRESOLVED pairs and each unmatched candidate. Agreement on closed outlines alone does not establish a traversable room. |
| Marker position and extent | Match wall-associated glyphs within 12 px by centre in each pass. Compare the visual appearance, centre displacement, orientation-independent endpoint error and absolute span difference. A matched marker passes if centres are within 8 px and within summed radii. Extent passes if both endpoints are within 8 px and within summed endpoint radii, and span lengths differ by at most 8 px and at most twice the summed endpoint radii. A missing span contributes an unresolved comparison. |
| Wall endpoints | In the common sample, match like traces if both endpoints are within 15 px after reversal if needed. Report the endpoint errors and summed radii. Count a pair as reproducible when both endpoints are within 12 px and within summed radii. Compare wall disposition and record how many reproducible raw traces have no supported semantic room assignment, plus the number present in raw but absent from the semantic sample. Keep the 8-trace cap and interruptions visible in the report. |
| Connections and terminal rooms | Align matched region centres before comparing links. Compare undirected confirmed room pairs and count shared and one-sided edges, including edges to unmatched regions. For matched rooms, compare the terminal status and measured departure evidence. Count disagreements, and count any shared TERMINAL decision that another visible fact contradicts or the V1 parser cannot represent. Record which missing link or frontier causes a failed projection. |
| Uncertainty and effort | Tabulate UNKNOWN, AMBIGUOUS and UNRESOLVED by field/type, incomplete searches and missing radii, split by frame, pass and order. Separate agreed uncertainty from discordant claims. Report individual durations and median by pass. Time-limited partial searches provide lower bounds for recorded feature counts and cannot pass marker completeness. |

### Readiness thresholds

- Semantic readiness requires player localization on both frames, reproducible Stage 0 arrival-room centre, and a reproducible Stage 3 semantic graph. Require at least three matched Stage 3 ROOM centres with in-radius agreement, at least 75% symmetric region match agreement (2 × matches divided by the sum of recorded candidates), and at least 80% class agreement among matches. Require at least one shared confirmed room-to-room link and one shared supported terminal decision. The two reviewers' confirmed link sets and terminal-room sets must agree after alignment, and the retained terminal assessments must project into version 1 without invented departures. Record orientation as usable, unresolved or discordant. Consistent unresolved orientation can pass with a pooled prior path. Discordant confident orientation is a blocker. Require the semantic marker threshold below as well.
- Marker readiness is assessed independently in both passes. In each complete frame pair require at least 2 matched glyphs at Stage 0 and 5 at Stage 3, at least 80% symmetric marker match agreement, and at least 80% of matched glyphs passing both the centre and extent checks. Use measured figures for both passes, including matches with missing extent in the denominator.
- Raw readiness requires player localization and marker readiness in the raw passes, plus at least four matched Stage 3 wall traces with at least 75% of wall matches reproducible. Evidence for a raw information advantage requires at least two jointly reproduced wall traces or markers that cannot enter the V1 graph without unsupported semantic assumptions, or at least two jointly reproduced marks missing from both semantic returns under comparable complete searches. Report the evidence and durations even when these thresholds pass. Treat an order effect or a time-limited pass as a qualification when comparing effort.

### Decision gate

Choose one primary direction only after the owner provides the returns. Apply the first supported rule in this order.

1. **A · Continue the room-based experiment** if semantic readiness passes and no observed representation issue blocks using those records.
2. **B · Controlled representation revision** if a specific, small change such as a missing-origin alternative or one parser relation accounts for the blocker and the other semantic prerequisites pass. Describe how to test the revision independently.
3. **D · Static game asset investigation** if geometry and localization otherwise pass, one verified mapping of a glyph or template could resolve the primary disputed semantic decision, and a provenance-checked reference route exists.
4. **C · Raw Geometry Fingerprinting research** if raw readiness and information advantage pass and room identity, orientation or connectivity failures remain after ruling out the narrower fixes above.
5. **E · INCONCLUSIVE** when the paired evidence cannot support a specific choice. Missing returns leave the gate pending.

This two-frame comparison estimates agreement and effort on this pilot only. It does not measure direction accuracy. A recommendation requires a separate owner decision before implementation.

## Arbitrary teleport requirement

| Dependency | Version 1 experiment | Eventual runtime implication |
| --- | --- | --- |
| Entrance identity and orientation | Known scenario is arrival from Level 1. Orientation is optional and has pooled lookup. | A cold start after a teleport can lack arrival history and any reliable facing. Treat orientation as optional evidence when visible. |
| Entrance-relative coordinates | The original origin drives player region and room-centre sectors. The current model's geometry features depend on that origin. | A player-centred frame can be built from a readable marker in the current image. Translation is then local and bearings can stay in native axes after a consistent scale check. Geometry-relative anchors are another option when stable visible features can be localized, with ambiguous alignments explicitly represented. Both alternatives require a separate protocol and validation. |
| Continuous observation | Evaluation uses arrival and three later checkpoints. Individual predictor calls consume one observation and a stage-fitted table. Previously observed geometry can be present in the input automap. | A runtime observation should work without continuous history. Optional same-map state can help only with reliable identity and registration after the camera moves. Cold start and camera jumps need separate tests. |
| Room centres and connectivity | Baseline needs a player position. Geometry requires at least one room centre and can accept zero links and a partial graph. A complete graph is used for offline split integrity. | Dependence on previously identified rooms adds a cold-start bottleneck. Visible line and marker measurements can survive without room segmentation. Their predictive value remains unknown. |
